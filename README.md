# Soul Spark React Website

A responsive single-page website built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Add your images
Place these files in the `public` folder:
- `logo.jpeg`
- `pic.jpeg`
- `course-handwriting.jpg`
- `course-graphology.jpg`
- `course-academic.jpg`
- `course-parenting.jpg`
- `course-life-coach.jpg`
- `course-gita.jpg`

## Build

```bash
npm run build
```
